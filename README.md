# NextChat · NOWYQS 定制版

**原项目完整 README：**[ChatGPTNextWeb/NextChat](https://github.com/ChatGPTNextWeb/NextChat/blob/main/README.md)

本 README 仅记录本 fork 相对原版的差异；原版的通用功能、安装、部署与配置说明以上游 README 为准。

## 定制差异

### 自动图片生成与连续改图

- 不再把 `gpt-image-2` 作为普通聊天模型暴露在模型选择列表中。
- 开启“启用图片生成”后，对明确的生图或基于当前聊天图片的修改请求进行语义判别：
  - 新图请求自动使用图片生成接口；
  - 后续改图请求自动使用图片编辑接口，并复用本聊天中最近可用的图片。
- 普通文本、代码与分析请求仍使用当前选定的文本模型，不会误走图片接口。
- 每个对话可单独关闭“启用图片生成”；默认开启。
- `gpt-image-2` 只在服务端的图片生成、图片编辑路径中放行，不会恢复为通用聊天模型。
- 针对 `gpt-image-2` 的参数兼容性：不会发送 DALL·E 3 专用的 `style` 参数。

### 输入区快捷控制

- 输入工具栏右侧新增常显的“模型”和“思考”快捷控件。
- 模型控件展开后可切换当前模型，并可直接开启或关闭图片生成。
- 思考控件支持 `low`、`medium`、`high`、`xhigh`、`max`；不支持该能力的模型会明确显示“不适用”。
- 下拉面板向聊天历史区域展开，带最大高度与内部滚动，避免被输入区裁切。

### 验证范围

- 已验证真实图片生成与基于生成图的图片编辑请求。
- 连续改图依赖同一浏览器资料中的图片缓存；清理站点数据、切换浏览器或图片缓存失效后，历史图片不能继续作为编辑源。
